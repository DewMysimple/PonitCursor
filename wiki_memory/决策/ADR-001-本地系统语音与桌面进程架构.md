# ADR-001｜本地系统语音与桌面进程架构

## 状态

`superseded`，由 [[决策/ADR-004-内置Kokoro离线语音后端|ADR-004 内置 Kokoro 离线语音后端]] 替代。

## 背景

PointCursor 要在阅读时快速播报英文词，并满足断网可用、不依赖账号或网络服务、不阻塞鼠标和托盘设置窗口的要求。

## 决策

主程序使用 C# / .NET Framework 4.8 WinForms 常驻系统托盘，发音使用 `System.Speech.Synthesis` 和本机已安装英文语音；选区读取放入同目录的 `PointCursor.Reader.exe`，通过标准输入输出发送短请求和结果。

## 理由

- Windows 自带语音和 .NET Framework 可直接部署，满足离线和低依赖目标。
- 辅助功能接口可能被第三方应用卡住，独立读取进程可在约 900 毫秒后终止并重启，主 UI 仍可响应。
- 主进程保存的只有设置和运行时状态，不需要建立网络服务或缓存单词历史。

## 影响

- 正面影响：便携、无需管理员权限，旧系统环境容易复现；新单词会取消旧语音，不排队。
- 代价或风险：语音质量和语言取决于 Windows 语音包；没有英文语音时无法播报。辅助进程崩溃或超时会丢弃本次请求。

## 验证方式

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test -Package`，确认自动测试、桌面流程和针对程序的出站网络阻止测试均通过；在设置中试听 `hello` 并检查已安装语音列表。
