# ADR-009｜限定美式与英式系统语音

用户后续明确要求按系统语音方案添加声音，只保留英式和美式；替代此前固定 Zira 的语音范围。

1. 使用一个 System.Speech/SAPI 合成后端。VoiceCatalog 按精确地区 en-US、en-GB 与 Enabled 筛选，不因语言前缀为 en 就接纳其他口音。
2. 设置保存 Voice，列表显示“美式/英式 · 声音名称”。默认优先 Zira；保存的声音失效时明确提示，再选择目录中的可用声音。无可用声音时禁用试听。
3. 每次请求捕获声音、语速、音量；声音切换取消旧请求和预热。SAPI 选择后核对名称，避免默默使用系统默认声音；PCM/WASAPI 播放实现继续共用。
4. 系统语音由 Windows 或兼容厂商安装，安装后重启应用刷新目录。产品不包含模型、下载器、注册表桥接或多引擎路由；构建和发音无需联网。
5. ADR-008 的独立输入线程、纯手势状态机、来源快照、900ms Reader 超时及取消恢复原则继续有效。此前删除的 Kokoro/Node/ONNX 不恢复。

代价：其他电脑需要安装兼容系统声音；Windows 讲述人中可见不代表 System.Speech 能调用，以程序目录和 diagnose 实测为准。
