# 当前约束

- 目标为 Windows x64、.NET Framework 4.8、WinForms；不下载依赖。语音仅 **Microsoft Zira Desktop**，不自动切到其他系统声音，不卸载或修改系统语音。
- 仅单个英文词，允许内部撇号、连字符；拒绝密码、数字、网址、多词和跨进程命中。
- 输入钩子必须独立消息线程，回调不做磁盘、UI、进程或辅助功能操作；手势算法与 Win32 调用分离。
- 完成手势的来源窗口和类型不可被后续前台状态覆盖。读取独立进程约 900ms 超时，新请求可取消旧请求；不增加无界重试或历史队列。
- 优先保护 Obsidian 实时预览、源码、阅读模式；高亮格式变化不应截短原词。复杂插件、权限与混合 DPI 未完整验证。
- 只读已授权来源的辅助功能范围和用户明确复制的新文本，不改笔记，不主动复制，不改剪贴板，不记录单词/按键历史。
- 构建产物、设置、测试库、浏览器缓存和账号信息不能提交；桌面测试使用独立合成数据，复制写入测试需明确选择 `--copy`。
- 完成工程变更必须验证、同步必要记忆和日志、运行 memory lint 与 diff check、创建一次 Git 提交并推送。失败时保留提交并说明原因。
