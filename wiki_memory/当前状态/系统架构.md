# 系统架构

主进程是 WinForms 托盘应用，取词在独立 `PointCursor.Reader.exe` 中完成。语音只有 Microsoft Zira Desktop，通过 System.Speech 后台合成为内存 PCM，再由 WASAPI 播放。

单实例按 Windows 会话、用户及正式/QA 版本隔离。重复启动通过现有消息窗口请求显示设置，由启动进程交接前台权限并聚焦返回的窗口；隐藏和最小化均恢复，不再提示“已在运行”。接收窗口在托盘初始化完成后发布，冷启动最多等待约 3 秒，消息调用最多等待 1 秒；旧实例已退出时可重新取得互斥成为主实例。没有新增轮询常驻线程或 IPC 依赖。

| 模块 | 职责与边界 |
| --- | --- |
| `App` / `SettingsForm` | UI 线程编排请求、托盘、剪贴板和设置 |
| `InputMonitor` | 专用 STA 消息循环安装鼠标/键盘钩子；只投递最新完成的选择或明确 Ctrl+C，避免 UI 卡顿使钩子超时 |
| `SelectionGesture` | 无 Win32 依赖的手势状态机，按事件按下时间判断双击，允许第二下长按和阈值内抖动 |
| `SelectionClient` | 在线程池启动/停止进程并串行读写；900ms 超时、取消、坏响应、退出后重建，退出与读取共享进程锁 |
| `SelectionReader` / `LegacySelection` | Chromium/Electron 优先经过密码保护的 IA2 文档接口，其余 UIA；UIA 不可用仍可尝试受保护的 MSAA/IA2 |
| `Core` | 单词过滤、选择代次、每次复制票据和 XML 设置 |
| `SpeechService` / `SapiSpeechEngine` | 仅固定 Zira，后台合成，最新请求替换旧请求及旧预热 |
| `AudioOutput` / `PcmAudio` | 24kHz PCM16 单声道完整采样播放，设备打开时 150ms 静音准备，正常选词不另加等待 |

## 请求链路

1. 鼠标按下时由命中窗口取得来源顶层 HWND；松开后提交起止坐标及明确的拖选/双击类型。双击按两次按下的事件时间判断，支持时间戳回绕；松开后的切窗不重新决定来源。
2. UI 约 10ms 后请求辅助进程。七字段协议使用 `gesture`（拖选）、`double`（双击）、`guard`（复制保护）；五字段 `selection` 仅用于诊断真实选区，不启用范围重建。
3. 优先读真实选区；已清空时按手势重建。双击类型随请求传递，不用 1px 位移猜测。Obsidian 高亮插入 `==` 时保留片段与包围词校正。IA2 空范围进入重建而非直接忽略；无结果最多再试两次，仍受进程超时约束。
4. 每条路径独立检查密码、来源进程与单词范围。文档全局选区在检查实际命中控件之后读取，避免密码框与旧普通选区并存时误读。
5. 合法词通过请求代次门控再交给 Zira；普通点击、键盘或切窗不停止发音，新的完整选择/复制可取消旧读取。
6. Ctrl+C 必须由真实输入触发、新剪贴板序列号、来源窗口仍在前台且控件安全；不模拟复制、不读取旧剪贴板。

仅保存 `%LOCALAPPDATA%/PointCursor/settings.xml` 中的语速、音量和复制开关。旧 Voice 字段被忽略，下次保存移除。没有模型、Node 工作进程、临时合成 WAV 或运行时下载。
