# 系统架构

> 只记录当前有效的模块关系、数据流、运行方式和关键技术边界。

## 架构概览

PointCursor 是一个无窗口驻留的 WinForms 托盘应用。主进程在用户会话中安装低级鼠标、键盘钩子和剪贴板格式监听器；选区读取由独立的 `PointCursor.Reader.exe` 完成，以便第三方辅助功能接口卡住时可以在约 900 毫秒后终止，不阻塞托盘 UI。读取结果经过单词规则、请求代次和重复门控后交给所选语音后端：Windows 语音由 `System.Speech.Synthesis` 播放，Kokoro 由独立 Node.js 工作进程完成音素转换和 ONNX 推理，再播放临时 WAV。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| `TrayApp` / `MessageWindow` | 托盘菜单、设置窗口、剪贴板与输入消息编排 | WinForms、`Native` | `src/App.cs` |
| `InputMonitor` | 全局低级鼠标/键盘钩子，识别拖选、双击、Ctrl+C 和失效事件 | Win32 `SetWindowsHookEx` | `src/InputMonitor.cs` |
| `SelectionClient` | 启动并复用读取辅助进程，处理取消、超时和重启 | `PointCursor.Reader.exe`、命名管道式标准输入输出 | `src/SelectionClient.cs` |
| `SelectionReader` | 校验前台窗口、控件状态并优先读取 UIA TextPattern 选区 | UI Automation | `src/SelectionReader.cs` |
| `LegacySelection` | 为 Electron/Obsidian 渲染窗口补充 MSAA/IAccessible2 选区读取 | `Accessibility.dll`、`oleacc.dll` | `src/LegacySelection.cs` |
| `WordRules` / gates | 过滤单词、取消旧请求、阻止同一次选择重复播报 | .NET 基础类库 | `src/Core.cs` |
| `SpeechService` | 汇总 Windows 与 Kokoro 英文语音，选择后端、停止旧读音并异步发声 | `System.Speech`、`KokoroSpeechEngine` | `src/SpeechService.cs` |
| `KokoroSpeechEngine` | 管理本地工作进程、请求取消、WAV 临时文件和播放生命周期 | `third_party/kokoro-runtime`、`SoundPlayer` | `src/KokoroSpeechEngine.cs` |
| `SettingsForm` / `AppSettings` | 中文设置、语速音量、试听和本地 XML 持久化 | WinForms、`%LOCALAPPDATA%` | `src/SettingsForm.cs` / `src/Core.cs` |

## 数据流或请求流

1. 鼠标按下时使上一轮请求失效；拖动释放或双击释放后记录前台窗口、释放坐标和剪贴板序列号。
2. 主进程等待 250 毫秒合并事件，调用读取辅助进程。辅助进程先检查窗口是否为自身、密码控件或非安全状态，再尝试 UIA `TextPattern.GetSelection`，失败时对 Electron 渲染窗口尝试 IA2。
3. 读取结果限制为单个英文词（可含内部撇号或连字符）；不合规则丢弃。新鼠标/键盘事件会取消旧请求，当前选区只允许一次播报。
4. 选词成功后由所选英文语音异步播放。Windows 后端直接调用 SAPI；Kokoro 后端复用已加载模型的工作进程，生成 24 kHz WAV 后播放。新词停止旧音频；若旧 Kokoro 请求仍在推理，则终止旧工作进程，不形成队列。
5. Ctrl+C 仅在检测到用户真实按键、且窗口产生新的剪贴板序列号后读取短文本；不主动复制、不改写剪贴板，并再次确认控件状态。

## 运行与部署

双击 `dist/PointCursor/PointCursor.exe` 后，主进程和同目录读取辅助进程一起运行；选择 Kokoro 时按需启动 `Kokoro/node.exe worker.mjs`。设置存于当前用户 `%LOCALAPPDATA%\PointCursor\settings.xml`。构建不需要 NuGet、npm 或网络，使用 Windows 自带 .NET Framework 4.8 C# 编译器并复制已纳入源码的 Git LFS 资产。退出时卸载钩子、剪贴板监听器、辅助进程、Kokoro 工作进程、临时 WAV 和语音资源。
