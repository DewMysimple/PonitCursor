# 项目概览

PointCursor 是 Windows x64 / .NET Framework 4.8 / WinForms 离线划词发音工具，面向 Obsidian 和暴露辅助功能选区的桌面应用。

语音支持已安装、启用的 **美式（en-US）和英式（en-GB）SAPI 5 系统声音**，默认优先 Microsoft Zira Desktop。用户在后续要求中明确增加这两类声音；继续沿用单一 System.Speech 合成后端，Kokoro、Node/ONNX/模型资产保持移除。

双击或拖选单个英文词后约 10ms 开始读取；来源窗口与手势类型被锁定，后续普通输入不会撤销请求。明确 Ctrl+C 是独立重听入口。程序不主动复制、不修改笔记、不保存单词历史。

2026-09-27 已通过 117 项自动检查、100 次 RichTextBox 连续双击、输入线程卡顿后首次新手势恢复、Obsidian 三模式共 60 次连续双击及浏览器密码保护。鼠标改为专用线程 Raw Input，音频增加设备时钟停滞恢复；同一进程两轮各闲置 330 秒后的首次双击、拖选及后续复选全部通过，具体证据见本轮日志和 COMPATIBILITY。多小时驻留仍需实际使用反馈。
