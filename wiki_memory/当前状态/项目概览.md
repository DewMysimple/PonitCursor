# 项目概览

PointCursor 是 Windows x64 / .NET Framework 4.8 / WinForms 离线划词发音工具，面向 Obsidian 和暴露辅助功能选区的桌面应用。

语音固定为 **Microsoft Zira Desktop**。用户已明确不再需要其他声音，因此已删除 Kokoro、Node/ONNX/模型/声线、后端切换和语音选择配置；不修改操作系统安装的其他语音。

双击或拖选单个英文词后约 10ms 开始读取；来源窗口与手势类型被锁定，后续普通输入不会撤销请求。明确 Ctrl+C 是独立重听入口。程序不主动复制、不修改笔记、不保存单词历史。

当前版本已通过 98 项自动检查、100 次 RichTextBox 连续双击、两次 UI 卡顿后继续识别、Obsidian 三模式共 60 次连续双击及浏览器密码保护回归；多小时驻留仍需实际使用反馈。
