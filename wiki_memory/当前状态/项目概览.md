# 项目概览

> 这是 Agent 每次工作首先需要理解的项目摘要。保持简短，只记录当前有效事实。

## 项目名称

PointCursor（Windows 离线划词发音工具）。

## 项目目标

在 Windows 桌面后台运行，用户用鼠标拖选或双击选中一个英文单词后，记录来源窗口和手势起止坐标，约 10 毫秒后读取并使用本机英文系统语音或内置 Kokoro 神经语音播报。划词完成后立即切换窗口或点击别处不会撤销这次播报。主要服务 Obsidian 阅读、实时预览和源码模式，也为其他暴露辅助功能文本范围的应用提供支持；自动取词失败时可用 Ctrl+C 补充发音，同一选区每次明确复制都可重听。

## 当前阶段

首版已实现并完成可运行构建；内置 Kokoro-82M int8 ONNX 离线后端，提供 20 个美式、8 个英式英文声线，同时保留 Windows 系统语音。源码、构建脚本、自动测试、桌面集成测试、Obsidian 三种模式验证记录和便携发布包均已准备。Microsoft Zira Desktop 路径已缩短选区等待、锁定完整划词手势、取消后续窗口／光标状态干扰，并能在 Obsidian 立即写入 `==word==` 后恢复原词，支持同词重复 Ctrl+C。发布目录为 `dist/PointCursor`；`dist/PointCursor.zip` 的根层就是程序根目录，不含同名包装文件夹。

## 主要用户或使用者

在 Obsidian、浏览器或普通文本控件中阅读英文、希望快速确认单词读法的 Windows 用户。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `src/` | C# 核心实现：托盘应用、全局输入、选区读取、语音与设置 |
| `tests/` | 单元测试、辅助测试窗口、浏览器与 Obsidian 集成测试脚本 |
| `third_party/kokoro-runtime/` | 随包发布的 Node.js、ONNX Runtime、Kokoro 模型、声线与许可证 |
| `build.ps1` | 使用系统 C# 编译器构建、测试和打包 |
| `dist/` | 本机生成的可运行目录与 ZIP 发布包，默认不纳入 Git |
| `wiki_memory/` | Agent 工程记忆：状态、决策、知识和任务日志 |

## 重要入口

- `src/App.cs`：WinForms `ApplicationContext`、系统托盘、消息窗口与单实例入口。
- `src/SelectionReader.cs`：独立选区读取辅助进程入口。
- `build.ps1`：构建入口；`-Test` 执行自动检查，`-Package` 生成 ZIP。
- `README.md`：面向使用者的中文说明。
- `COMPATIBILITY.md`：真实环境兼容性和验证记录。
