# 2026-09-09｜集成 Kokoro 离线语音

- 时间：2026-09-09（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：把用户提供的本地 NVIDIA Kokoro 声线加入 PointCursor，形成可离线发布和选择的 Kokoro 语音后端。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- Kokoro 声线 `.bin` 不是 SAPI 语音，必须配套 ONNX 模型、音素转换和推理运行时；采用独立本地工作进程，不把神经推理放入 WinForms UI 线程。
- 保留 Windows `System.Speech`，新增内置 Kokoro 后端；设置页暴露 20 个美式、8 个英式 Kokoro 英文声线。
- 随包发布 Node.js x64、裁剪后的 Transformers.js/ONNX Runtime/phonemizer、Kokoro-82M int8 模型和全部原始声线；运行时禁止远程模型。
- 大型模型和二进制通过 Git LFS 管理；构建过程不执行 NuGet、npm 或模型下载。

## 检查与操作

- 检查本地 NVIDIA Kokoro 仓库、许可证、54 个声线文件和 JavaScript 推理实现；确认原目录缺少 ONNX 模型。
- 使用 `onnx-community/Kokoro-82M-v1.0-ONNX` 的量化模型完成本地原型，裁剪非 Windows、浏览器和图像处理运行时后复验。
- 新增 C# Kokoro 工作进程客户端，支持声线发现、语速/音量映射、复用、旧请求终止、临时 WAV 播放与清理。
- 更新设置语音列表、构建/打包脚本、使用说明、兼容性记录、架构状态和决策。

## 文件变更

- 新增 `src/KokoroSpeechEngine.cs` 与 `third_party/kokoro-runtime/`。
- 修改 `src/SpeechService.cs`、`src/App.cs`、`tests/Tests.cs`、`build.ps1`、`README.md`、`COMPATIBILITY.md` 和相关工程记忆。
- 新增 `.gitattributes`，让模型、声线和运行时二进制进入 Git LFS。

## 测试与验证

- 64 项自动检查通过；新增 28 个英语声线发现、美英声线列表、语速映射、C# 桥接美式/英式实际生成与播放验证。
- Kokoro 工作进程直接冒烟测试生成有效 24 kHz WAV；本地模型加载显式禁用远程下载。
- `build.ps1 -Test -Package`、设置窗口渲染、记忆体检和 `git diff --check` 通过。
- 发布目录和 ZIP 包含完整 `Kokoro/` 运行时；测试结束后无残留 Kokoro Node 进程。

## 待确认长期记忆

- 低性能 CPU 首轮延迟、长期内存曲线和高频连续换词仍需后续真实环境数据。

## 问题、结果与下一步

- 结果：PointCursor 可在设置中选择并离线播放 28 个 Kokoro 英文声线，同时保留 Windows 系统语音。
- 遗留问题：Kokoro 首次加载和资源占用高于系统语音；其他语言声线随包保留但尚未向只读英文单词的 UI 暴露。
- 下一步：按当前待办补充性能与压力验证。
