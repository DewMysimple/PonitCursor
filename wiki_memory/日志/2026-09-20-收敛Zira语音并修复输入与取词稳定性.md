# 收敛 Zira 语音并修复输入与取词稳定性

## 目标与确认范围

用户明确只需要 Microsoft Zira Desktop，并要求改善双击漏读、删除冗余、保持可维护性；按仓库约定完成验证、记忆同步、一次提交及远程推送。没有调用子代理，没有修改操作系统安装的语音。

## 修改

- 删除 Kokoro 引擎、RuntimeAssets、整个已跟踪便携运行时、Node/ONNX/模型/声线、完整性工具、基准测试和 LFS 属性。打包改为八个明确文件，清理本机生成目录中的已知旧模型资产。
- SpeechService 固定 Zira，SAPI 后台只选择这一声音；删除多后端分支及 Voice 设置字段，设置页改固定标签；兼容旧配置，保留语速、音量和复制开关。新请求亦能取消旧预热。
- 输入钩子使用专用消息线程，避免 UI 卡顿引发 Windows 静默移除。新增独立 SelectionGesture 状态机，事件按下时间计双击，允许第二下长按和阈值内抖动，仅保留最新待处理意图。
- 来源顶层 HWND 在按下时确定，不在处理松开时重取前台；桌面回归暴露并修复了立即切窗竞态。双击类型通过 `double` 协议传递到 UIA/IA2，去掉 1px 猜测。
- Chromium/Electron 优先受保护 IA2，避免先遍历缺少 TextPattern 的 UIA 包装层；读文档全局选区前检查实际命中控件的密码状态。空 IA2 范围可以继续按手势重建。UIA 包装异常可进入独立受保护降级。
- Reader 启停/管道移到后台，保持 900ms 超时；退出与读取不再竞争 Process 对象，校验响应字段，取消、超时、异常退出和坏编码后均可恢复。
- 更新 README、COMPATIBILITY、测试说明、当前状态、模块/构建/运维知识；ADR-004 标记 superseded，由 [[决策/ADR-008-固定Zira与独立输入线程]] 替代。

## 验证

- 自动检查 98 项通过；包括 100 次 Reader 连续请求、故障后恢复、取消挂起旧请求后新请求继续、退出取消。
- RichTextBox 连续交替双击 100/100；两次 UI 阻塞 1.5s 后继续发音、第二下长按、立即切窗/点击、暂停恢复和密码跳过通过。
- Obsidian 1.13.7 三模式各 20 次连续双击（60/60）；基础双击/拖选、编辑模式立即高亮通过。独立实例重启后的基础回归最终通过。
- 精确选区 21/21，最终轮次测试笔记 SHA-256 不变；调试时一次哈希检查碰到刚恢复测试内容后的异步保存，待其保存完后复验通过。
- Chrome 五项通过，包括前后台密码保护与多词拒绝。默认未选择 `--copy`，不操作用户剪贴板；未运行管理员防火墙或新音频回录。
- 固定语音设置页渲染已检查；diagnose 使用 Zira 合成 hello，内存 WAV 55144 字节。
- 本机桌面双击至播放状态 205–255ms；Obsidian 优先 IA2 前 410–659ms，之后 252–375ms，均包含约 200ms 双击动作及状态轮询，非声学测量。

## 结果与边界

工程收敛为固定 Zira 和两个产品进程。规则、输入、取词、合成和播放各自保持明确职责，新增回归针对实际故障机制；不承诺多小时驻留、复杂插件、混合 DPI 和所有硬件环境已充分验证。

调试阶段出现的首次高亮漏读没有被当作已通过结果；最终复验通过后仍保留长期使用反馈待办。历史日志和 Git 历史不删除，不清理 Git LFS 历史对象。
