# 添加美式与英式系统语音选择

## 用户要求与范围

用户明确要求沿用此前建议的系统语音方案添加声音，只要英式和美式。该新要求替代固定 Zira 的产品限制；保留单一 SAPI/System.Speech 后端，不恢复 Kokoro、Node、ONNX 或模型资产。

## 实现

- 新增独立 VoiceCatalog，按 Enabled 和精确 Culture en-US/en-GB 筛选并稳定排序；排除中文及其他英语地区。
- AppSettings 保存 Voice，旧 Zira-only 配置沿用默认；旧 Kokoro/已移除声音解析到可用声音并提示，优先 Zira。语速、音量和复制偏好保留。
- 设置页下拉显示“美式/英式 · 声音名称”，选择即时生效并保存。没有可用声音时禁用下拉和试听。
- SAPI 请求捕获声音名称快照，在合成线程切换并核对实际选中的声音；预热和新请求取消旧请求，继续使用原 PCM/WASAPI 输出。
- diagnose 枚举并逐个合成两类声音；`-RequireBothAccents` 为实际安装验收提供严格检查。构建仅增加一个本地 C# 文件，无新下载依赖。

## 本机语音安装

起初桌面接口只有英文 Zira 和中文 Huihui。按本轮授权安装 Windows en-US/en-GB TextToSpeech 组件；未卸载其他系统声音，未改变显示语言、代理、Windows Update 策略或复制注册表语音 token。

直接 Add-WindowsCapability 遇到更新端点错误 0x80240438。本地 Source 方式也报告源不完整；随后使用与本机版本相符的微软原始组件 CAB。UUP 元数据仅用于定位文件，载荷来自微软 delivery 服务器，先核对 SHA-256 和系统适用性，再通过 Windows 包管理器校验并安装；系统服务补齐了所需更新组件。安装过程全程禁止自动重启，最终两类组件均为 Installed，RestartNeeded 均为 False。下载与临时元数据留在忽略的 build/qa，不进入源码或发布包。

最终桌面接口可调用：Microsoft David Desktop（en-US）、Microsoft Zira Desktop（en-US）、Microsoft Hazel Desktop（en-GB）。程序不列出中文或其他口音，也不包含自动系统安装功能。

## 验证

- 最终 `build.ps1 -Test -OutputDirectory build/candidate`：113 项通过，包含逐个真实声音的共享输出、同词重听、声音快照、旧配置、精确过滤、UI 选择和缺失目录。
- `diagnose.ps1 -RequireBothAccents`：David/Zira/Hazel 均通过实际选择核对并生成非空 hello WAV，分别为 56466/55144/58228 字节；不播放、不联网、不改设置。
- `voice_selection_qa.py`：十项通过，覆盖实际下拉列表范围、三种声音选择/保存/播放、保留其他设置、退出重启后声音恢复并发音。测试仅用 QA 设置并恢复原内容，不操作鼠标或剪贴板。
- 设置页下拉渲染已检查。未重跑 Obsidian/浏览器整套压力测试；取词实现未改变，历史验证保持原日期。
- 调试期间修正了测试侧的 WinForms 同步上下文顺序，以及跨进程 ComboBox 通知的控制 ID 位宽、选择文本读取方式；没有通过放宽口音或声音验收条件规避失败。

## 限制与待确认长期记忆

其他电脑需要自行安装兼容的系统声音；讲述人自然语音和第三方声音未经本轮实机验证。没有待确认的新偏好，英美限定与添加系统声音均由用户明确提出。
