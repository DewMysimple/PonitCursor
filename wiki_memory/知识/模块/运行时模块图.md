# 运行时模块图

当前完整模块与数据流以 [[当前状态/系统架构]] 为唯一当前说明，本页记录维护入口。

- 修改鼠标识别：先改 `SelectionGesture` 并补充状态机回归，再检查 `InputMonitor` 的 Win32 快照和专用消息循环。按下时锁定来源、事件时间计双击、松开时提交意图。
- 修改读取：`SelectionClient` 负责进程生命周期，`SelectionReader` 负责 UIA 和路由，`LegacySelection` 负责 MSAA/IA2 ABI 和保护；不要把跨进程 COM 读取放回 UI 或钩子线程。
- Chromium 的包装 UIA 节点可能不暴露 TextPattern；优先直接读渲染器 IA2，且必须在文档全局选区前检查命中控件密码状态。
- 修改发音：`VoiceCatalog` 管理 en-US/en-GB 筛选和选择恢复，`SpeechService` 验证并提交声音快照；`SapiSpeechEngine` 只合成；`AudioOutput`/`PcmAudio` 只处理代次和 PCM 输出。保持单一系统语音后端。
- 修改配置：`AppSettings` 仅持久化 Voice、Rate、Volume、CopyToSpeak。缺少 Voice 时优先 Zira；旧声音失效交给目录恢复，UI 下拉列表只使用已筛选目录。

协议、安全、取消和相应测试见 `tests/Tests.cs`、`tests/desktop_qa.py`、`tests/obsidian_live_qa.py`。真实桌面测试默认不操作剪贴板。
