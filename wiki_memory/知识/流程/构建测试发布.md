# 构建、测试与发布

使用 Windows PowerShell 执行 `build.ps1 -Test -Package`，或双击 `buildStart.cmd` 只构建打包；`buildStart.cmd -Test` 加跑自动检查。仅依赖系统 C# 编译器、System.Speech、UI Automation 等系统程序集，不使用 NuGet/npm/模型或 Git LFS 资产。

1. 编译 `PointCursor.Core.dll`（Core 与 SelectionGesture）、主程序和独立 Reader。
2. `-Test` 编译隔离 QA 主程序、Fixture、AudioProbe 和 Tests；规则、旧配置迁移、英美语音过滤、真实声音切换、声音快照、PCM、超时/取消/崩溃/坏响应恢复和连续协议检查必须通过。语音验收另运行 `diagnose.ps1 -RequireBothAccents` 和 `tests/voice_selection_qa.py`，确认两类声音实际可用、切换和重启保留。
3. 输入/取词改动运行 `python tests/desktop_qa.py --stress 100`；Electron 改动运行独立 Obsidian 三模式与 Chrome 保护测试。桌面需要空闲，默认不复制；只有显式 `--copy` 且可安全恢复时才操作剪贴板。
4. `-Package` 从明确的八个文件创建 `dist/PointCursor.zip`，根层直接含 EXE/DLL/config、README、COMPATIBILITY、diagnose。旧模型、工具或测试数据不能混入归档。
5. 构建会清理输出目录中已知旧 `Kokoro/` 与 `tools/check-runtime.ps1`，不清空任意输出内容；路径必须位于本仓库 build/dist。
6. 同步记忆日志、运行 `python wiki_memory/工具/memory_lint.py index` 与 `check`、`git diff --check`，提交并推送。

默认发布目录 `dist/PointCursor`；使用 `-OutputDirectory build/candidate` 可先验证候选而不覆盖运行中的正式版。替换正式版前退出旧程序，替换后可用 `--quiet` 恢复托盘。
