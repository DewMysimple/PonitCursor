# 部署与故障排查

PointCursor 使用已安装的美式/英式 SAPI 系统语音，默认优先 Microsoft Zira Desktop。保持主 EXE、Reader、Core DLL 和两个 config 在同一目录；无需模型、Node、ONNX 或随包语音资产。

- 先在设置页选择标有“美式”或“英式”的声音并试听 hello。选项即时生效并保存；原声音失效时提示并优先回到 Zira，再选择其他可用英美声音；完全没有兼容声音时禁用试听。
- 已在后台时，再次打开 EXE 会直接恢复并聚焦已有设置窗口，最小化也可恢复；关闭窗口仍保留托盘实例。`--quiet` 仅影响首次启动。更新到此版本时需退出旧进程，因为旧版没有实例唤醒接收逻辑。
- `diagnose.ps1` 枚举并逐个合成美式/英式声音的 hello，不播放、不联网、不改设置；`-SkipSynthesis` 只检查目录，`-RequireBothAccents` 要求两类真实声音均存在。
- 在 Windows 的“时间和语言 → 语音 → 添加语音”安装 English (United States) 或 English (United Kingdom)，随后重启 PointCursor。以诊断脚本中的目录为准；讲述人自然语音不保证可供 SAPI 使用。程序本身不下载或修改系统组件。
- 试听正常但选词无声：检查暂停状态及目标应用的选区支持；保持单词选中后明确 Ctrl+C 可补充读取，控件无法确认安全时保守跳过。
- 设置为 `%LOCALAPPDATA%/PointCursor/settings.xml`，仅 Voice/Rate/Volume/CopyToSpeak。无 Voice 的旧配置默认 Zira，Kokoro 等已失效选项由目录恢复，其他偏好保留；损坏 XML 回到默认值并提示。
- 暂停释放音频设备，恢复重新准备；输入监听仍运行。鼠标改用专用线程 Raw Input，避免低级鼠标钩子被静默移除；键盘钩子定期更新。
- Reader 无响应约 900ms 后终止，下一请求重启；取消、退出和坏协议响应都有回归测试。正式程序不写选词诊断日志。
- 升级推荐退出后解压到空目录；构建脚本清理本机输出中旧 Kokoro 资产，发布包只包含明确清单。系统其他语音不受影响。
- 热插拔、睡眠、混合 DPI 和长时间驻留仍需反馈；软件合成/回录不证明最终硬件发声质量。

- 后台闲置回归运行 `tests/idle_qa.py --idle-seconds 330 --cycles 2`，须使用独立 Obsidian 测试库；不以打开设置或试听预热作为恢复步骤。音频时钟停滞自动重开，设备实际播放完成才释放当前 PCM。
