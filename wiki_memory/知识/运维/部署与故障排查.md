# 部署与故障排查

PointCursor 固定使用 Microsoft Zira Desktop。保持主 EXE、Reader、Core DLL 和两个 config 在同一目录；无需模型、Node、ONNX 或语音声线目录。

- 先从设置页试听 hello。缺少 Zira 会明确提示，安装后重启；程序不自动切换其他语音。
- `diagnose.ps1` 检查 Zira 并在内存中合成 hello，不播放、不联网、不改设置；`-SkipSynthesis` 只检查安装状态。
- 试听正常但选词无声：检查暂停状态及目标应用的选区支持；保持单词选中后明确 Ctrl+C 可补充读取，控件无法确认安全时保守跳过。
- 设置为 `%LOCALAPPDATA%/PointCursor/settings.xml`，仅 Rate/Volume/CopyToSpeak。旧 Voice 被忽略，下次保存移除；损坏 XML 回到默认值并提示。
- 暂停释放音频设备，恢复重新准备；输入监听仍运行。输入钩子独立于 UI，避免界面或磁盘卡顿触发系统静默移除。
- Reader 无响应约 900ms 后终止，下一请求重启；取消、退出和坏协议响应都有回归测试。正式程序不写选词诊断日志。
- 升级推荐退出后解压到空目录；构建脚本清理本机输出中旧 Kokoro 资产，发布包只包含明确清单。系统其他语音不受影响。
- 热插拔、睡眠、混合 DPI 和长时间驻留仍需反馈；软件合成/回录不证明最终硬件发声质量。
